## 📖 Deep Dive: How ChronoPaw Works

### The Observer's Lens

At its heart, ChronoPaw functions as a **memory-resident observer**. It monitors the game's memory footprint to understand the current state of your playthrough, without writing any persistent changes to the executable.

- **Read Operations:** The primary function is reading variables like position, inventory, and stats.
- **Modification Layer:** When you choose to invoke a temporal shift or resource adjustment, ChronoPaw sends a **command packet** to the game's memory space, which is the same mechanism the game uses internally for its own mechanics. This ensures a stable and reliable interaction.
- **Revertibility:** All changes are stored in a **session log**. If you wish to undo a specific modification, you can simply click the "revert" option, and the original state is restored.

This architecture guarantees a low risk of instability and ensures that the game's core logic remains untouched.
